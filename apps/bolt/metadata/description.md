# Bolt.diy - AI-Powered Development Environment

Bolt.diy is an advanced AI coding assistant that supports multiple LLM providers including OpenAI, Anthropic, Google AI, and local models through Ollama. It provides a full web development environment directly in your browser.

## Key Features

- **Multiple AI Provider Support**: Use your preferred AI model including:
  - OpenAI (GPT-3.5, GPT-4)
  - Anthropic (Claude)
  - Google AI (Gemini)
  - Local models via Ollama
  - And many more

- **Development Environment**:
  - Integrated code editor
  - Real-time terminal
  - Preview window
  - Git integration

- **Project Management**:
  - Download as ZIP
  - Git repository support
  - Project templates
  - Version history

## Configuration

The app requires at least one AI provider to be configured. You can set up multiple providers for different use cases.

### Required Setup
1. Add API keys for your preferred AI providers in the configuration
2. For local models (Ollama), ensure the service is running and accessible
3. Access through your Runtipi dashboard
