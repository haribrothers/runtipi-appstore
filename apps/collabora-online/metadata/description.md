# Collabora Online Development Edition (CODE)

Collabora Online is a powerful online office suite that lets you edit documents directly in your web browser. It is based on LibreOffice technology and provides a modern, collaborative editing experience.

## Features

- Full-featured online office suite
- Real-time collaboration
- Compatible with Microsoft Office formats
- Support for OpenDocument formats
- Built-in file viewer
- Mobile-friendly interface

## Configuration

### Admin Console
- Access the admin console at your configured domain
- Use the admin credentials set during installation
- Monitor and configure the service

### Integration
- Can be integrated with:
  - Nextcloud
  - ownCloud
  - Other compatible platforms

### Security
- SSL termination handled by Traefik
- Admin authentication required
- Configurable frame ancestors for embedding

## Usage
1. Access through your browser at the configured domain
2. Log in with admin credentials
3. Use directly or integrate with other applications

## Note
This is the Development Edition (CODE) which is free for testing and personal use. For production environments with more than 20 users, consider the subscription-based versions.
