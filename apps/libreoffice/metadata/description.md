# LibreOffice Online

LibreOffice is a free and powerful office suite, and a successor to OpenOffice.org. Its clean interface and feature-rich tools help you unleash your creativity and enhance your productivity.

## Features

- **Writer** (word processing)
- **Calc** (spreadsheets)
- **Impress** (presentations)
- **Draw** (vector graphics and flowcharts)
- **Base** (databases)
- **Math** (formula editing)

## Document Formats

- Full support for OpenDocument Format (ODF)
- Support for Microsoft Office formats
- Export to PDF built-in
- Many other document formats supported

## Configuration

The app stores documents in the `/documents` directory within your app data folder. You can access this directory to manage your files directly.

### File Storage
- All documents are stored persistently in the configured data directory
- Documents can be accessed and modified through the web interface
- Changes are saved automatically

## Usage
1. Access LibreOffice through your Runtipi dashboard
2. Create or open documents through the web interface
3. All changes are automatically saved
4. Files are stored in your configured data directory
